# Lab 02 – Provisioning an Ubuntu VPS on Contabo

> **Status:** Planned

This lab will document the complete process of provisioning an Ubuntu Server on a Contabo VPS.

It will include:

- Selecting the VPS plan
- Deploying Ubuntu Server
- Connecting via SSH from macOS
- Updating the operating system
- Verifying network connectivity
- Initial server validation
- Screenshots
- Troubleshooting
- Lessons learned

This document will be completed once the VPS has been provisioned.
